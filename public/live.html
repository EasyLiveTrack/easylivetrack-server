📡 Server & Tracking Protocol

100% Free Map Layers: Powered by OpenStreetMap, OpenTopoMap, and Esri Satellite with zero third-party API keys required.

Security & Spam Protection: GPS ingestion requires a valid API key. Only authorized devices can transmit data:

GET http://<SERVER_IP>:5055/?id={sessionId}&key={apiKey}&token={viewToken}&lat={lat}&lon={lon}&speed={speed}&batt={batt}

or via HTTP POST with Authorization: Bearer {apiKey}.

Live viewer links contain a read-only token:

http://<SERVER_IP>:5055/live/{sessionId}?token={viewToken}

Note: When tracking outdoors via LTE cellular networks, ensure the server domain or public IP is reachable over the internet.
